Software

We develop and maintain open research software for statistical genetics, polygenic prediction, multi-omics integration, pleiotropy analysis, mediation analysis, and transcriptome-wide association studies.

Source code is available through the biostatpzeng GitHub account.

CONTO

Composite null test for trans-ethnic genetic overlap

A gene-centric method for detecting trans-ethnic genetic overlap under a composite null hypothesis testing framework.

coxlmm

Linear mixed-effects Cox model

A Cox mixed model procedure for prognosis analysis that integrates clinical covariates and gene expression levels to estimate clinical and genetic variance components.

DPR

Latent Dirichlet process regression

A non-parametric genetic prediction framework for complex traits, designed to model latent genetic architecture and improve risk prediction from genome-wide markers.

GAMM

GRS-informed gene-based association mixed model

A genetic risk score-informed gene-based association mixed model for testing gene-level associations in complex trait studies.

glmm

Generalized linear mixed model

R code for generalized linear mixed model analysis, supporting association modeling with structured random effects.

HMAT

Aggregated transcriptome-wide association

Harmonic mean p-value aggregation for transcriptome-wide association studies, combining evidence across expression prediction models.

iMAP

Integrative pleiotropic mapping

An integrative mapping approach for pleiotropic association and annotation selection in genome-wide association studies.

IUSMMT

Survival mediation analysis

Intersection-union survival mixture-adjusted mediation testing for high-dimensional omics data and time-to-event outcomes.

JMAP

Jackknife model averaging prediction

R functions for jackknife model averaging prediction of complex phenotypes with gene expression levels and external pathway information.

LRT

Likelihood ratio testing for SNP-set association

Likelihood ratio test procedures for SNP-set association studies based on mixed models, supporting gene-level association analysis in genome-wide data.

MAGIC

Measurement-error adjusted local genetic correlation

A measurement-error adjusted local genetic correlation method for studying shared genetic architecture between traits.

MAIUP

Mixture-adjusted pleiotropy testing

Mixture-adjusted intersection-union testing for detecting pleiotropic associations under composite null hypotheses in genetic and omics studies.

MCA

Multilocus association methods

R implementation and comparison resources for multilocus, SNP-set, and gene-based association methods using summary statistics.

MTV

TWAS-mediated variance estimation

A method for transcriptome-wide association analysis and mediated variance estimation, supporting the study of gene expression-mediated disease mechanisms.

TLegene

Transfer-learning eGene analysis

A transfer-learning framework for eGene identification that borrows genetic similarity across samples to strengthen expression quantitative trait analysis.

transFDR

Trans-ethnic false discovery rate analysis

A trans-ethnic false discovery rate framework for replication analysis of index SNPs across populations.

TransferLearning

Trans-ethnic genetic prediction via transfer learning

Transfer-learning methods for trans-ethnic genetic prediction, designed to improve prediction by borrowing information across populations.

transPGS

Transfer-learning polygenic score

Transfer-learning methods for polygenic score construction, with emphasis on improving genetic prediction in underrepresented populations by leveraging cross-population information.

ZIP

Adaptive Lasso for zero-inflated count models

R functions for adaptive Lasso analysis of zero-inflated Poisson and zero-inflated negative binomial models.
